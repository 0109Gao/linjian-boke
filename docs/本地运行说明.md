## 二、启动步骤（按顺序）

### 1. 启动 MySQL

MySQL 是 ZIP 版（非 Windows 服务），需手动启动：

```bash
cd D:/mysql/app/mysql-26.10.0-winx64/bin
./mysqld.exe --console
```

> 启动后 3306 端口监听即成功。root 密码：`123456789`

### 2. 初始化数据库（仅首次）

```bash
mysql --default-character-set=utf8mb4 -u root -p123456789 < sql/schema.sql
```

> **关键**：必须加 `--default-character-set=utf8mb4`，否则中文种子数据会因客户端默认 GBK 字符集报 `Incorrect string value` 错误。

### 3. 启动后端

```bash
cd backend
mvn spring-boot:run -Dspring-boot.run.arguments="--server.port=8080"
```

> **关键坑**：WorkBuddy 环境注入了 `SERVER__PORT=40652` 环境变量，会通过 Spring Boot 宽松绑定覆盖 `application.yml` 里的 `server.port=8080`，导致端口冲突启动失败。**必须用 `--server.port=8080` 命令行参数显式覆盖**（命令行参数优先级高于环境变量）。

### 4. 启动前端

```bash
cd frontend
npm install   # 仅首次
npm run dev
```

前端地址：http://localhost:5173（Vite 已配 `/api` 代理到后端 8080）

## 四、已修复的问题

1. **端口冲突**：`SERVER__PORT` 环境变量覆盖 `server.port`，用命令行参数解决。
2. **slug 含中文**：`generateSlug` 正则保留中文导致 URL 不规范，改为只保留英文数字。
3. **种子数据中文报错**：需 `--default-character-set=utf8mb4`。
4. **MyBatis SQL 日志中文乱码**：关闭 stdout 日志输出（纯控制台显示问题，不影响功能）。
